## Starter prompt

````text
Act as an educational financial coach based in the UK. I want to understand how I can find out more about my retirement savings and options. Please note, I am seeking generic, factual education only, not regulated financial advice or personalised recommendations. If you are linking external websites, only use UK government websites or moneyhelper.org.uk.
Please provide an easy-to-understand overview covering the following areas:

1. Pension Types: Explain the types of pensions in the UK (e.g. defined benefit and defined contribution) and how I can find out what I have.
2. The State Pension: Briefly explain how the UK State Pension operates and how it typically factors into a broader retirement income strategy.
3. Key Things to Consider and How to Know Whether I'm on Track: Detail the main things I need to be aware of when planning my retirement income (such as my lifestyle, inflation and how long my money may need to last), and explain how I can work out how much I might need and whether I'm on track.
4. Next Steps: Provide a sensible, actionable checklist of practical steps I should take, and impartial reference websites (e.g. moneyhelper.org.uk) I could use, to make myself more prepared for retirement, including before I speak to a regulated financial adviser.

Please ensure your response is structured clearly with headings and bullet points, uses plain British English with no jargon, and maintains an objective, coaching tone throughout. Offer me the option to explore further any topic that you have raised.
````

## Answer-style paragraphs

### In the style of real world case studies (`caseStudy`)

````text
How to present your answer:
For each question, explain it through one or two short worked examples of believable people in the UK, with ages and circumstances I could recognise. Show what they had, what they chose and what happened, then what that shows in general, with no separate explanation. Say plainly that they are illustrations, not real people and not recommendations for me. Keep figures simple, and check they add up. This is only about how you present the answer: everything else I have asked for still applies.
````

### With numbers and facts (`factual`)

````text
How to present your answer:
For each question, put the key numbers and facts first, in short bullet points or a small table, with little narrative around them. Say which tax year every figure is for and where I can check it. Label estimates and assumptions and keep them apart from facts. Where you work something out, show the steps. Say when you are unsure of a figure rather than guess. This is only about how you present the answer: everything else I have asked for still applies.
````

### Short and simple descriptions (`simple`)

````text
How to present your answer:
Keep it short and simple, as you would for a friend. Put the main point first. Use everyday words and short sentences, and explain any pension term in plain words the first time you use it. Use no more than five bullet points for each question and leave out detail I did not ask for. I should be able to take it in at one reading. This is only about how you present the answer: everything else I have asked for still applies.
````

## How the prompt is put together

The page code that assembled each kind of prompt in this release, copied from `index.html`.

### Personalised route

This builds the prompt from the answers given in the wizard. Text in quotes is sent as written; the rest is filled in from what the user entered.

````js
generatePrompt = () => {
  const f = this.state.fields;
  const sources = this.getSources(), concerns = this.getConcerns();
  const selectedKeys = Object.keys(this.state.browseSelected);
  let p = 'I would like your help understanding my retirement income situation. Please treat me as an individual and give me specific, practical guidance based on the details I am providing.\n\n';
  p += '--- MY PERSONAL DETAILS ---\n';
  if (f.age) p += 'My age: ' + f.age + '\n';
  if (f.partnerAge) p += "Partner's age: " + f.partnerAge + '\n';
  if (f.retireAge) {
    p += 'Target retirement age: ' + f.retireAge + '\n';
    if (f.age) {
      const yrs = parseInt(f.retireAge) - parseInt(f.age);
      if (yrs > 0) p += 'Years to retirement: approximately ' + yrs + '\n';
    }
  }
  p += 'Country / region: ' + (f.country || 'not specified') + '\n';
  if (f.employment) p += 'Employment status: ' + f.employment + '\n';
  if (f.health) p += 'Health status: ' + f.health + '\n';
  if (f.dependants) p += 'Financial dependants: ' + f.dependants + '\n';
  if (f.risk) p += 'Investment risk tolerance: ' + f.risk + '\n';

  // The partner's pension answer only counts while a partner's age is entered (PO-27)
  const partnerAccess = hasPartnerAge(f) ? f.partnerPensionAccess : '';
  const hasFinance = f.income || f.pension || f.savings || f.property || f.pensionAccess || partnerAccess || f.financeNotes;
  if (hasFinance) {
    p += '\n--- WHAT I HAVE NOW ---\n';
    if (f.pension) p += 'Pension savings: ' + f.pension + '\n';
    if (f.savings) p += 'Other savings and investments: ' + f.savings + '\n';
    if (f.property) p += 'Property and debts: ' + f.property + '\n';
    if (f.pensionAccess) p += 'What I have taken from my pensions so far: ' + f.pensionAccess + '\n';
    if (partnerAccess) p += 'What my partner has taken from their pensions so far: ' + partnerAccess + '\n';
    if (f.income) p += 'Current income and pension contributions: ' + f.income + '\n';
    if (f.financeNotes) p += 'Other notes on my finances: ' + f.financeNotes + '\n';
  }
  p += '\n--- MY RETIREMENT GOALS ---\n';
  // The lifestyle answer is also the expected spending (PO-24). A Retirement Living Standards
  // level is named, never given as an amount, so the AI works from the current published figure.
  if (RLS_LEVELS.includes(f.lifestyle)) {
    p += 'Lifestyle expectation: the "' + f.lifestyle + '" level of the Pensions UK Retirement Living Standards.\n';
    p += 'Expected spending in retirement: please use the current published figure for that level and my household. Say which figure you used and list it as an assumption. Those figures are spending after tax and leave out housing and care costs.\n';
  } else if (f.lifestyle === 'Other' && f.target) {
    p += 'Target monthly lifestyle spending in retirement: ' + f.target + '. This is what I expect to spend, so treat it as an after-tax figure.\n';
  } else {
    p += 'Expected spending in retirement: not provided. Please estimate it, and list your estimate as an assumption.\n';
  }
  if (f.partTime) p += 'Part-time work in retirement: ' + f.partTime + '\n';
  if (f.estate) p += 'Estate / inheritance priority: ' + f.estate + '\n';
  if (f.plans) p += 'Key plans: ' + f.plans + '\n';
  if (sources.length || f.srcNotes) {
    p += '\n--- INCOME I EXPECT IN RETIREMENT ---\n';
    sources.forEach((src) => { p += '- ' + src.name + (src.detail ? ': ' + src.detail : ': amount not provided') + '\n'; });
    if (f.srcNotes) p += 'Notes: ' + f.srcNotes + '\n';
  }
  // A described "Other concern" counts only while its box is ticked. A tick with no
  // description adds nothing: "Other" tells the AI nothing by itself (PO-28).
  const otherConcern = f.c_other && f.concernOtherText ? f.concernOtherText.trim() : '';
  if (concerns.length || otherConcern) {
    p += '\n--- MY CONCERNS ---\n';
    if (concerns.length) p += 'Main concerns: ' + concerns.join(', ') + '\n';
    if (otherConcern) p += 'Other concern: ' + otherConcern + '\n';
  }
  if (selectedKeys.length) {
    p += '\n--- MY QUESTIONS ---\n';
    selectedKeys.forEach((k, i) => {
      const q = this.findQuestion(k);
      if (q) p += (i + 1) + '. ' + q.humanVersion + '\n\n';
    });
  }
  if (!selectedKeys.length) {
    p += '\n--- MY QUESTION ---\nBased on my details above, what is your honest assessment of my retirement income situation? What are the key risks I face, and what practical steps should I be taking now?\n\n';
  }
  if (f.question) p += 'Anything else I want you to know: ' + f.question + '\n';
  p += '\n--- HOW TO HANDLE ASSUMPTIONS AND TAX ---\n';
  p += 'Before anything else, give a numbered list of every assumption you are making about my situation, including any you draw from the details above.\n';
  p += 'Do not infer anything I have not told you. In particular, do not assume whether I or my partner have triggered the Money Purchase Annual Allowance (MPAA), which tax band we are in, or what State Pension we are entitled to. Use only what I have stated; whether a pension pot is crystallised or uncrystallised does not tell you whether the MPAA applies. If a missing detail would change your answer, ask me rather than guessing.\n';
  p += 'Whenever you quote an income or spending figure, give it both after tax and before tax and label which is which. The first time you do this, explain the difference in one plain sentence.\n';
  p += '\nPlease structure your response with: (1) an honest assessment of my current position, (2) the key gaps or risks I should address, (3) practical options or strategies to consider, and (4) questions I should be asking a qualified financial adviser.\n\nNote: I understand this is educational guidance only, not regulated financial advice.';
  this.setState({ outputText: this.withStyle(p) });
};
````

### Answer style

This adds the paragraph for the answer style the user chose to the bottom of the prompt.

````js
withStyle = (text) => {
  const block = (PROMPTS_DATA.styleBlocks || {})[this.state.browseAnswers.style];
  return block && block.text ? text + '\n\n' + block.text : text;
};
````
