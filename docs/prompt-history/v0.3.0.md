````text
Please provide a comprehensive, easy-to-understand overview covering the following areas:

1. Core Income Options: Explain the main ways to take income from a UK defined contribution pension (e.g., annuities, flexi-access drawdown, and taking lump sums/UFPLS).
2. Pros and Cons: Outline the general advantages and disadvantages of each of these main options.
3. The State Pension: Briefly explain how the UK State Pension operates and how it typically factors into a broader retirement income strategy.
4. Key Risks to Consider: Detail the main risks I need to be aware of when planning my retirement income (such as inflation, longevity risk, and market volatility).
5. Next Steps: Provide a sensible, actionable checklist of practical steps I should take to organise my financial information before I eventually speak to a regulated financial adviser.

Please ensure your response is structured clearly with headings and bullet points, uses plain British English, and maintains an objective, coaching tone throughout.
````

### Foundations of a plan

#### foundation_1: Target retirement income

Shown on the site:

````text
What should I aim for as a realistic monthly retirement income?
````

Prompt:

````text
**Part 1: Core Task**

You are an AI assistant specialized in providing comprehensive, general information on UK retirement income planning. Your goal is to guide an individual through the complexities of retirement income planning by helping them set realistic income targets and understand key UK-specific funding mechanisms.

Address the following, ensuring all information is practical, actionable, and tailored to the UK context:

1.  **Critical Factors for Income Goals**: Outline the essential factors individuals should consider when establishing a monthly retirement income goal in the UK (e.g., current lifestyle aspirations, regional cost of living, inflation's impact, and personal longevity expectations).
2.  **Illustrative UK Income Targets**: Provide realistic, illustrative monthly income targets for different UK lifestyle scenarios (e.g., Modest, Comfortable, Affluent), specifically referencing current PLSA (Pensions and Lifetime Savings Association) Retirement Living Standards (e.g., 2024/25 figures) where applicable.
3.  **UK Retirement Funding Methods Overview**: Briefly describe the main UK methods used to fund retirement income (e.g., State Pension, private pension drawdown, annuities, ISAs/investments, part-time work, rental income). For each, concisely explain its typical role and contribution within a diversified retirement income strategy, rather than deep mechanics.

Ensure all financial information is accurate, up-to-date (e.g., 2024/25 State Pension figures, current ISA allowances), and specifically relevant to the UK.

**Part 2: Formatting & Guardrails**

*   **Crucial Disclaimer**: Immediately at the start of your response, include a clear, prominent disclaimer stating that the information provided is for general educational and informational purposes only and does not constitute regulated financial advice. You are an AI assistant providing general guidance, not a regulated financial advisor.
*   **Target Style**: Adopt the style of real-world case studies, offering practical, scenario-based insights.
*   **Conciseness & Length**: Your response must be highly concise, adhering strictly to a total length of **250-500 words**. Prioritize key information and avoid exhaustive explanations to ensure readability.
*   **Bottom Line Up Front (BLUF)**: Following the disclaimer, begin with the most critical takeaways or an executive summary, allowing for immediate comprehension of the core advice.
*   **Clarity & Structure**: Maintain excellent structure, clarity, and readability, utilising bullet points or short paragraphs where appropriate for maximum impact.
*   **Drill-down Offer**: Conclude your response by explicitly offering to 'drill down' into any of the discussed topics, encouraging the user to ask follow-up questions for more detailed information.
````

## How the prompt is put together

The page code that assembled each kind of prompt in this release, copied from `index.html`.

### Personalised route

This builds the prompt from the answers given in the wizard. Text in quotes is sent as written; the rest is filled in from what the user entered.

````js
generatePrompt = () => {
  const f = this.state.fields;
  const sources = this.getSources(), concerns = this.getConcerns();
  const selectedKeys = Object.keys(this.state.browseSelected);
  let p = 'I would like your help understanding my retirement income situation. Please treat me as an individual and give me specific, practical guidance based on the details I am providing.\n\n';
  p += '--- MY PERSONAL DETAILS ---\n';
  if (f.age) p += 'My age: ' + f.age + '\n';
  if (f.partnerAge) p += "Partner's age: " + f.partnerAge + '\n';
  if (f.retireAge) {
    p += 'Target retirement age: ' + f.retireAge + '\n';
    if (f.age) {
      const yrs = parseInt(f.retireAge) - parseInt(f.age);
      if (yrs > 0) p += 'Years to retirement: approximately ' + yrs + '\n';
    }
  }
  p += 'Country / region: ' + (f.country || 'not specified') + '\n';
  if (f.employment) p += 'Employment status: ' + f.employment + '\n';
  if (f.health) p += 'Health status: ' + f.health + '\n';
  if (f.dependants) p += 'Financial dependants: ' + f.dependants + '\n';

  const hasFinance = f.income || f.pension || f.savings || f.equity || f.debts || f.contributions || f.pensionAccess || f.partnerPensionAccess || f.financeNotes;
  if (hasFinance) {
    p += '\n--- WHAT I HAVE NOW ---\n';
    if (f.pension) p += 'Total pension / retirement savings: ' + f.pension + '\n';
    if (f.savings) p += 'Other savings and investments: ' + f.savings + '\n';
    if (f.equity) p += 'Property equity: ' + f.equity + '\n';
    if (f.debts) p += 'Outstanding debts: ' + f.debts + '\n';
    if (f.pensionAccess) p += 'What I have taken from my pensions so far: ' + f.pensionAccess + '\n';
    if (f.partnerPensionAccess) p += 'What my partner has taken from their pensions so far: ' + f.partnerPensionAccess + '\n';
    if (f.income) p += 'Current annual household income: ' + f.income + '\n';
    if (f.contributions) p += 'Annual pension contributions: ' + f.contributions + '\n';
    if (f.financeNotes) p += 'Other notes on my finances: ' + f.financeNotes + '\n';
  }
  p += '\n--- MY RETIREMENT GOALS ---\n';
  if (f.spending) p += 'Expected spending in retirement: ' + f.spending + (f.spendingBasis ? '. This figure is: ' + f.spendingBasis : ' (I have not said whether this is before or after tax)') + '\n';
  else p += 'Expected spending in retirement: not provided. Please estimate it, and list your estimate as an assumption.\n';
  if (f.target) p += 'Target monthly income in retirement: ' + f.target + (f.targetBasis ? '. This figure is: ' + f.targetBasis : '') + '\n';
  if (f.lifestyle) p += 'Lifestyle expectation: ' + f.lifestyle + '\n';
  if (f.partTime) p += 'Part-time work in retirement: ' + f.partTime + '\n';
  if (f.estate) p += 'Estate / inheritance priority: ' + f.estate + '\n';
  if (f.plans) p += 'Key plans: ' + f.plans + '\n';
  if (sources.length || f.srcNotes) {
    p += '\n--- INCOME I EXPECT IN RETIREMENT ---\n';
    sources.forEach((src) => { p += '- ' + src.name + (src.detail ? ': ' + src.detail : ': amount not provided') + '\n'; });
    if (f.srcNotes) p += 'Notes: ' + f.srcNotes + '\n';
  }
  const hasConcerns = concerns.length || f.risk || f.buffer;
  if (hasConcerns) {
    p += '\n--- MY CONCERNS AND RISK PROFILE ---\n';
    if (concerns.length) p += 'Main concerns: ' + concerns.join(', ') + '\n';
    if (f.risk) p += 'Risk tolerance: ' + f.risk + '\n';
    if (f.buffer) p += 'Emergency buffer: ' + f.buffer + '\n';
  }
  if (selectedKeys.length) {
    p += '\n--- MY QUESTIONS ---\n';
    selectedKeys.forEach((k, i) => {
      const q = this.findQuestion(k);
      if (q) p += (i + 1) + '. ' + q.humanVersion + '\n\n';
    });
  }
  if (f.question) {
    p += (selectedKeys.length ? '' : '\n--- MY QUESTION ---\n') + f.question + '\n';
  }
  if (!selectedKeys.length && !f.question) {
    p += '\n--- MY QUESTION ---\nBased on my details above, what is your honest assessment of my retirement income situation? What are the key risks I face, and what practical steps should I be taking now?\n';
  }
  p += '\n--- HOW TO HANDLE ASSUMPTIONS AND TAX ---\n';
  p += 'Before anything else, give a numbered list of every assumption you are making about my situation, including any you draw from the details above.\n';
  p += 'Do not infer anything I have not told you. In particular, do not assume whether I or my partner have triggered the Money Purchase Annual Allowance (MPAA), which tax band we are in, or what State Pension we are entitled to. Use only what I have stated; whether a pension pot is crystallised or uncrystallised does not tell you whether the MPAA applies. If a missing detail would change your answer, ask me rather than guessing.\n';
  p += 'Whenever you quote an income or spending figure, give it both after tax and before tax and label which is which. The first time you do this, explain the difference in one plain sentence.\n';
  p += '\nPlease structure your response with: (1) an honest assessment of my current position, (2) the key gaps or risks I should address, (3) practical options or strategies to consider, and (4) questions I should be asking a qualified financial adviser.\n\nNote: I understand this is educational guidance only, not regulated financial advice.';
  this.setState({ outputText: p });
};
````

### Prompt list route

This joins the prompts of the questions the user selected.

````js
copyAllSelected = () => {
  const ids = Object.keys(this.state.browseSelected);
  if (!ids.length) return;
  const text = ids
    .map((id, i) => {
      const q = this.findQuestion(id);
      return q ? `${i + 1}. ${q.quickSummary}\n${q.aiOptimised}` : '';
    })
    .filter(Boolean)
    .join('\n\n---\n\n');
  window.showPromptModal(text);
};
````
